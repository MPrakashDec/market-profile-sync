#### 7. Decoding the Option Matrix (`archive_json.M`)
StockMock packages its multi-strike chain into a compact numerical matrix:
- **`exp_entry.St`**: Base strike price (e.g., `22000`).
- **`exp_entry.M`**: Array of rows representing each strike and call/put:
  - `row[1]`: Premium (LTP).
  - `row[2]`: Strike offset from base (`Base Strike + row[2]` = actual strike).
  - `row[3]`: Open Interest (OI).
  - `row[4]`: Option Type (`0` = CE / Call, `1` = PE / Put).
  - `row[5]`: Implied Volatility (IV).
  - `row[6]`: Delta.

The parsed records are formatted into structured dictionaries:
