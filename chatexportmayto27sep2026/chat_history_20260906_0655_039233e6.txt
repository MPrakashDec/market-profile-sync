* **Client-Side Rendering (WebGL Canvas):**

   - Perform OCR / computer-vision pixel scraping on the rendered HTML5 canvas (fragile, slow, lossy), OR
   - Reverse-engineer GoCharting’s minified client-side JavaScript memory heap to read their internal canvas state variables.
2. **Computing It Ourselves Is Cleaner and Standardized:**  
   Market Profile (TPO distribution, 70% Value Area rule, Point of Control) is a strict, well-defined mathematical algorithm. Given standard 1-minute or 5-minute price data (or tick data), computing TPO counts, IB (Initial Balance), VAH, VAL, and POC in Python takes a few lines of vector math. You have complete transparency and control over session boundaries (e.g., 09:15–15:30 IST) without relying on browser rendering.
