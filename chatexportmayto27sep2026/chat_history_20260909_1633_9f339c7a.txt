### What is Graphify?

**Graphify** (`graphifyy` on PyPI) is an open-source tool built to solve AI context loss and hallucination in codebases. Instead of relying on traditional RAG (vector chunking/similarity search) or dumping raw files into context windows, it turns a codebase into a **deterministic knowledge graph**.

---

### Key Mechanics

1. **Deterministic AST Parsing (Tree-sitter):**
   * Parses Python, JS/TS, Go, Rust, etc., locally using Tree-sitter.
   * Extracts exact relationships: function call graphs, class inheritance, imports, and module dependencies without invoking an LLM.
2. **Semantic Linking for Docs/Assets:**
   * Uses an LLM pass only for non-code files (Markdown, specs, design notes) to connect conceptual documentation to specific code nodes.
3. **No Vector Database Required:**
   * Stores information as nodes (functions, classes, files) and edges (calls, imports, inherits, documents).
   * Queries traverse paths (e.g., *“If I modify function A, which routes and handlers break?”*), eliminating vector retrieval blind spots.
4. **Three Primary Outputs:**
   * `graph.json`: Machine-readable graph consumed by AI assistants/agents.
   * `GRAPH_REPORT.md`: Architectural overview and high-centrality node summaries.
   * `graph.html`: Interactive, force-directed visual map of the project.

---

### Relevance to Our Workspace & Operational Rules

In quantitative environments where:
* Strict file boundaries, exact call order, and analytical formulations (Black-76, futures vs. spot dependencies) must never be hallucinated,
* Memory footprints need to be light (avoiding bloated vector DBs on 8GB RAM setups),

A deterministic graph representation guarantees exact dependency tracing without wasting tens of thousands of tokens re-reading directory structures.
