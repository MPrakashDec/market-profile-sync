#### 1. CRITICAL MATH FLAW: `quant_paper_trader` Hard Invariant Crash on VWAP Breakdown (Phase 1)

```python

    if fut_vwap > 0 and fut_price < (fut_vwap - 5.0):
```

- **The Bug**:
  Suppose price is at **`24,040`** (breaking below VWAP `24,050`).
  If `put_wall` is populated as **`24,100`** (e.g. from an options wall or prior level higher than current price), then:
  `target_1_fut = 24100`.
  Now the check runs:
  `assert 24065 > 24040 > 24100` $\rightarrow$ **FALSE!**
- **The Consequence**: Because `target_1_fut` is higher than `fut_price`, the script hits `AssertionError` and **crashes immediately on Line 1** the moment a short breakdown signal is detected.
- **The Correct Math**: For a Put (short breakdown), the target must be *below* entry:
  `target_1_fut = put_wall if (0 < put_wall < fut_price) else (fut_price - 45.0)`
