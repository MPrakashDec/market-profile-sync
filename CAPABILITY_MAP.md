# Capability Map

Updated 2026-10-01.

## Proven
- Repository listing and metadata.
- Repository read/fetch.
- Branch creation.
- Git blob/tree/commit operations.
- File create/update/delete.
- Commit/ref comparison.
- Public repository and code search.
- Access to the linked account's visible repositories.

## Exposed but not yet proven
- Pull-request creation/update/review/merge.
- Issue mutations.
- Workflow reruns.
- Deeper CI inspection.

## Project-memory mechanisms to research
- Explicit versioned situation index.
- Durable decision ledger.
- Negative-knowledge register.
- Research register with provenance.
- Session handoff artifact.
- Repository map/codebase awareness.
- Cross-session observation memory.

## External mechanisms identified
- claude-mem: persistent observations, semantic retrieval, project context files.
- Aider: repository map and Git-native change/test loop.
- AGENTS.md: repository-local agent context/instructions.
- Superpowers: composable skills and structured agent workflow.

These are research inputs, not dependencies or endorsements.
